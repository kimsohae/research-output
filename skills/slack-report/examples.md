# Slack Examples

## Example — 사용자 이탈

### Good

신규 사용자 리텐션 하락은 **첫 7일 이탈 증가가 가장 큰 요인으로 보입니다.**

- 최근 3개월 7일 내 이탈률: **31% → 44%**
- 초기 설정 미완료 사용자에서 이탈이 가장 높았습니다.
- 다만 같은 기간 유입 채널도 변해, 초기 설정이 직접 원인이라고 단정하기는 어렵습니다.

**다음 액션:** 초기 설정 개선 실험을 진행하면서 채널을 통제한 cohort 분석으로 영향을 분리해보는 것을 제안합니다.

상세: [Confluence 링크]

### Bad

안녕하세요. 리텐션 관련해서 간단하게 조사한 내용 공유드립니다.

여러 데이터를 확인해봤는데 전반적으로 신규 사용자의 리텐션이
조금 좋지 않은 것으로 보이고 초기 설정 과정에도 일부 문제가
있을 수 있을 것 같습니다.

다만 다른 요인도 있을 수 있어서 추가 확인이 필요할 것 같습니다.

자세한 내용은 문서를 참고 부탁드립니다.

### Why bad

- 결론까지 오래 걸린다.
- 핵심 수치가 없다.
- 중요도 차이가 없다.
- 불확실성을 전달하는 것이 아니라 문장 전체가 흐릿하다.
- 읽은 뒤 필요한 행동을 알 수 없다.

## Example — 경쟁사

### Good

경쟁사 분석상 **기능 추가보다 초기 설정 단순화가 더 큰 차별화 포인트일 가능성이 있습니다.**

A/B 모두 자동화 기능은 이미 제공하고 있고,
차이는 `즉시 사용성 vs 커스터마이징`에 가깝습니다.

우리 고객 인터뷰에서도 초기 설정 복잡성이 도입 장애물로 반복됐습니다.

→ 다음 제품 검토에서는 기능 개수보다 **첫 가치 도달까지 필요한 설정 단계**를 우선 비교하면 좋겠습니다.

## Example — 의사결정 요청

### Good

**결정 필요: 신규 검색 기능을 이번 스프린트에 포함할지 정해야 합니다.**

추천은 **이번 스프린트에서는 제외**입니다.

- 사용자 요청은 확인됐지만 표본이 아직 작습니다.
- 현재 구현 시 예상 개발 비용은 약 2주입니다.
- 다음 주 사용자 인터뷰 6건에서 수요를 추가 검증할 수 있습니다.

지금 구현하면 빠르게 대응할 수 있다는 장점이 있지만,
수요가 제한적일 경우 2주의 개발 비용을 낭비할 가능성이 있습니다.

**제안:** 다음 주 인터뷰 결과를 확인한 뒤 결정.
